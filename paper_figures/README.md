# Paper figures

The four figures embedded in the published paper, and everything that
generates them. This folder is self-contained — the scripts write their
output here and nowhere else.

## Quickstart

```bash
cd paper_figures
python3 -m venv .venv && source .venv/bin/activate
pip install matplotlib numpy
python3 regenerate_fig3_fig4.py
python3 regenerate_class_distribution.py
```

Each script writes color + grayscale PNG and PDF copies to this folder.

## Figure map

File names are historical and don't match the paper's own Fig. 1-4 order —
use this table, not the filenames, to find a given figure.

| Paper figure | Shows | File | Script |
|---|---|---|---|
| Fig. 1 | Pipeline diagram | `pipeline_overview.pdf` | static asset, not script-generated (see below) |
| Fig. 2 | Per-class F1 by camera direction, for pixel/decision/feature fusion | `fig4_fusion_by_direction_color.{png,pdf}` | `regenerate_fig3_fig4.py` |
| Fig. 3 | Class distribution by camera direction | `dataset_class_distribution_trainval_color.{png,pdf}` | `regenerate_class_distribution.py` |
| Fig. 4 | Feature Fusion + shuffle correction (blind/classifier/oracle) | `fig3_shuffle_overall_color.{png,pdf}` | `regenerate_fig3_fig4.py` |

`captions.txt` has the exact caption text as printed in the paper.

## `regenerate_fig3_fig4.py` (Fig. 2 and Fig. 4)

Reads `figure_metrics_correct.json` in this folder and draws both figures —
no GPU, no re-running any model.

`figure_metrics_correct.json` is a hand-verified data file, not produced by
any script here. If the underlying eval numbers ever change, it has to be
re-verified and edited by hand; there's currently no automated path that
regenerates it.

## `regenerate_class_distribution.py` (Fig. 3)

Sample counts are hardcoded directly in the script — there's no input JSON.
They're estimates, reconstructed by measuring bar heights in
`dataset_class_distribution_trainval_color.webp` (the original reference
image, also in this folder) against its axis gridlines — see the script's
module docstring for the exact method. Close enough for the chart, but
don't treat them as exact.

## Fig. 1 (`pipeline_overview.pdf`)

Hand-designed diagram, not generated by a script. The editable sources are
`pipeline_v2_overview.svg` and `pipeline_v2_fig1_fusion.svg`, also in this
folder — edit those in a vector editor (e.g. Inkscape, Illustrator, Figma)
and re-export to PDF to update it.

## `paper_figure_metrics.py` and `figures-creation.ipynb`

`figures-creation.ipynb` is the Kaggle notebook that evaluates the trained
models and exports metrics; `paper_figure_metrics.py` is a small module it
imports to serialize those metrics to JSON. Both live here so they travel
together — don't move or delete either one on its own.

## Elsewhere in the repo

`workspace_output/` (repo root) is an archived snapshot of a full past
pipeline run (logs, checkpoints, figures as they were at that time). It's a
historical record, not part of this folder's tooling — leave it alone.
